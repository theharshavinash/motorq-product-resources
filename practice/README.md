# Practice

We give candidates real public datasets to practise on, not synthetic ones. This section points you to actual data and a working-session exercise: explore a messy real dataset under time pressure, then write a one-page recommendation. Before you do it live in the interview.

## This is not the interview dataset

The data you practise on is different from the data you will see in the interview. It is real, but in a different domain, so you cannot pattern-match your way through. **There is no answer key**, here or anywhere. We are not going to publish "the right answer," because in the real round there isn't one — there are defensible recommendations and indefensible ones. The point of practising is to learn the difference by doing it, not by checking your work.

## How to use it

1. Open [`brief.md`](brief.md) and pick one scenario.
2. Download the real dataset from the Kaggle link (free account required).
3. Spend about 60 minutes exploring. Use whatever tool you are fastest in — SQL, spreadsheet, Python, AI. The data is real and messy; decide what to believe before you build on it.
4. Write a one-pager using [`one-pager-template.md`](one-pager-template.md), in about 15 minutes.
5. Then reread what you wrote and ask: which of these claims can I actually defend, and which did I assert because it felt convenient?

Real data is messier than you expect — mixed units, missing values that mean different things, duplicates. That is exactly the habit this exercise is meant to surface: if your recommendation rests on a number you never sanity-checked, you have noticed something we will be looking for in the real round.
